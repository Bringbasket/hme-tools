# 前端开发规范

前端位于 `apps/web`，使用 Vue 3、TypeScript、Vite、Pinia 与 Tailwind CSS。

## 目录职责

```text
src/api/          请求封装与 DTO
src/components/   可复用组件
src/layout/       侧栏、顶栏和内容区
src/router/       静态路由与动态路由装配
src/stores/       跨页面状态
src/styles/       主题与组件基础样式
src/views/        页面，按功能域分组
```

## 约定

- Vue 组件使用 `<script setup lang="ts">`，请求和表单必须有明确类型。
- HTTP 请求统一经过 `src/api/http.ts`，页面不得自行创建 Axios 实例。
- 登录态和权限由 store 与路由守卫统一处理。
- 菜单来自后端动态路由；新增系统页面时同步定义菜单、组件路径和权限。
- 通用交互优先复用 `components/ui`，避免页面内复制组件实现。
- 图标使用 `lucide-vue-next`，图标按钮应提供可访问名称或提示。
- 列表加载、空数据、失败、无权限和提交中状态都必须可见。
