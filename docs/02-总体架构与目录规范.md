# 总体架构与目录规范

GoKeep 是前后端分离开发、生产环境可合并为单个 Go 二进制的基础后台框架。

## 系统结构

```text
Browser
  |-- development --> Vite :5173 -- /api proxy --> Gin :8080
  `-- production  --> Gin :8080 (embedded Web UI + API)
                                      |-- PostgreSQL
                                      |-- Redis
                                      `-- S3-compatible storage (optional)
```

后端只保留通用系统域：认证、授权、系统管理、数据库备份和静态资源服务。新增应用功能时应在 `server/internal/<domain>` 与 `apps/web/src/views/<domain>` 中独立组织。

## 目录

```text
apps/web/                 Vue 管理后台
  src/api/                HTTP 客户端
  src/components/         通用组件
  src/layout/             后台外壳
  src/router/             路由装配
  src/stores/             Pinia 状态
  src/views/              页面
server/
  cmd/server/             服务入口
  internal/api/           路由与静态资源
  internal/auth/          登录、注册、会话和动态路由
  internal/backup/        数据库备份与 S3 存储
  internal/common/        中间件与通用工具
  internal/config/        环境配置
  internal/db/            数据库连接
  internal/ent/           schema 与生成代码
  internal/redisx/        Redis 连接
  internal/system/        系统管理接口
deploy/compose/           本地依赖服务
scripts/                  开发和链路验证脚本
docs/                     工程规范
```

## 边界

- Handler 负责参数绑定、权限检查和响应；Service 负责规则与数据访问。
- API 统一位于 `/api/v1`，系统接口按资源分组。
- 浏览器不直接访问数据库、Redis 或对象存储。
- 配置来自环境变量和系统设置，敏感配置不得硬编码。
