# 技术栈规范

本文档记录 GoKeep 的技术基线。新增依赖、替换基础设施或改变前端平台能力时，必须先说明原因、影响范围和迁移方式，并同步更新本目录中的相关规范。

## 运行环境

| 部分 | 技术 | 基线 |
| --- | --- | --- |
| 工具链 | Node.js、pnpm | Node.js 20+、pnpm 11+ |
| 前端框架 | Vue、TypeScript、Vite | Vue 3、TypeScript 5.6、Vite 5 |
| 前端状态 | Pinia、Vue Router | Pinia 3、Vue Router 4 |
| 样式与组件 | Tailwind CSS、PostCSS、Radix Vue、Lucide | Tailwind 3.4、组件按需使用 |
| HTTP | Axios 统一封装 | 只能通过 `apps/web/src/api/http.ts` 发起业务请求 |
| 后端 | Go、Gin、Ent | Go 1.25+ |
| 数据库 | PostgreSQL | 15+ |
| 缓存 | Redis | 7+ |
| 对象存储 | S3 兼容服务 | 可选，用于备份等非核心文件 |

## 工程约定

- 前端位于 `apps/web`，由 pnpm workspace 管理；后端位于 `server`。
- 开发环境由 Vite 提供前端页面，并将 `/api`、`/healthz` 和 `/readyz` 代理到 Go 服务；生产环境把前端构建产物嵌入 Go 二进制。
- `apps/web/src/styles/theme.css` 和 `apps/web/tailwind.config.js` 是颜色、字体、间距和基础组件类的唯一入口。业务页面不得另建全局主题。
- 图标统一使用 `lucide-vue-next`；不能为已有图标手写 SVG。无法从图形理解含义的图标按钮必须提供 `aria-label` 和 `title`。
- 弹窗优先使用 `components/ui/Modal.vue` 或业务域的 `AppDialog.vue`；表格分页优先使用 `components/ui/Pagination.vue`。
- 业务功能按领域组织：前端使用 `src/views/<domain>`、`src/api/<domain>.ts` 和必要的 `src/stores/<domain>.ts`；后端使用 `server/internal/<domain>`。跨领域共享能力放入 `components`、`stores` 或 `internal/common`，不得复制到页面内。
- 引入新的 UI 组件库前，必须证明现有 Tailwind、Radix Vue 和本地组件无法满足需求，并评估包体积、主题一致性和无障碍影响。

## 主题与视觉基线

- 默认采用浅色管理台，支持通过 `dark` class 切换深色主题；主题切换不得改变布局尺寸或信息顺序。
- 品牌色使用 `brand` token（青绿色系）表达主操作和当前选中项；成功、警告、错误和处理中状态必须使用独立语义色。
- 管理台字体使用系统中文无衬线字体，字号不随视口缩放，字间距保持 `0`。
- 设计基线为固定侧栏、固定顶栏、受平台外壳控制的 `.page` 内容区，以及稳定的表头、工具栏和分页栏。
