# 技术栈规范

本文档记录 GoKeep 基础后台框架当前采用的技术与版本基线。新增依赖前应确认现有工具无法满足需求，并在代码评审中说明用途。

## 运行环境

| 部分 | 技术 | 基线 |
| --- | --- | --- |
| 前端 | Vue、TypeScript、Vite、Tailwind CSS、Pinia | Node.js 20+、pnpm 11+ |
| 后端 | Go、Gin、Ent | Go 1.25+ |
| 数据库 | PostgreSQL | 15+ |
| 缓存 | Redis | 7+ |
| 对象存储 | S3 兼容服务 | 可选，用于数据库备份 |

## 工程约定

- 前端位于 `apps/web`，使用 pnpm workspace 管理。
- 后端位于 `server`，模块路径为 `gokeep/server`。
- Ent schema 是数据库结构的唯一代码来源，生成代码随仓库提交。
- 开发环境由 Vite 将 `/api` 代理到 Go 服务。
- 生产构建先生成前端产物，再使用 `embed` 构建单二进制。
- 密码、令牌、数据库连接串和对象存储密钥不得提交到仓库。

## 质量检查

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm build
Set-Location server
go test ./...
go vet ./...
```
