# 数据库与缓存规范

## PostgreSQL

- PostgreSQL 15+，字符集 UTF-8，时间字段统一使用带时区时间。
- Ent schema 位于 `server/internal/ent/schema`，修改后运行 `go generate ./internal/ent`。
- 表和字段使用小写 snake_case；主键使用 `id`；关联字段使用 `<resource>_id`。
- 列表查询必须分页并限制最大页容量；排序字段必须使用白名单。
- 多步写操作需要事务，外部网络请求不应长时间占用数据库事务。

当前基础框架只包含以下数据域：

| 数据 | 用途 |
| --- | --- |
| `sys_users`、`sys_roles`、`sys_user_roles` | 用户与角色 |
| `sys_menus`、`sys_role_menus` | 动态菜单与权限 |
| `sys_dict_types`、`sys_dict_datas` | 数据字典 |
| `sys_configs` | 系统配置 |
| `sys_oper_logs` | 操作审计 |
| `backup_records` | 数据库备份记录 |

## Redis

Redis 用于会话、验证码、权限缓存和限流等可重建状态，不作为唯一持久化数据源。

```text
gokeep:session:<jti>
gokeep:captcha:<uuid>
gokeep:userperms:<user-id>
gokeep:emailcode:<email>
gokeep:emailcode:cooldown:<email>
```

- 所有临时键必须设置 TTL。
- 不得写入密码、SMTP 密码、S3 密钥等敏感值。
- 生产环境应启用认证、持久化与网络访问控制。

## 备份

备份模块生成压缩 SQL 文件，可保存到 S3 兼容存储，并支持定时执行、下载、删除和恢复。恢复会覆盖当前数据库，必须在执行前确认目标环境并先创建可用备份。
