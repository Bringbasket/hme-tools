# 移动端适配规范

后台以桌面端为主要体验，手机端至少保证登录、导航和系统管理页面可查看、可完成主要操作。

## 布局

- `<1024px` 时侧栏使用抽屉模式，打开后提供遮罩并可关闭。
- 页面水平内边距随断点缩小，不使用按视口宽度缩放字体。
- 表单在窄屏改为单列；按钮组允许换行，但主要操作位置保持稳定。
- 数据表放入横向滚动容器，操作列不得覆盖数据列。
- 弹窗宽度受视口约束，内容区可滚动，页脚操作始终可达。

## 交互

- 点击区域满足触屏操作，图标按钮保留可访问名称。
- 不为移动端复制整套页面组件；使用同一组件和响应式断点适配。
- 打开软键盘后，输入框、错误提示和提交按钮仍应可见。

## 验收

在 `390x844` 与 `375x812` 下检查登录、侧栏、列表、分页、表单和弹窗，确认无元素重叠、文字裁切和页面级横向滚动。
